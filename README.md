# SusOS

A chaotic, Among Us-themed web desktop simulator built because people that follow the tutorials 1:1 are boring as heck.

## Why I Built This
I wanted something super fun, lightweight, and genuinely hilarious to look at while showcasing my web dev stuff. Instead of a static page, SusOS bundles draggable windows, mini-games, and a full desktop experience into one.

## What It Actually Does
- **Interactive Desktop:** Fully draggable windows, live system clock, and a custom welcome screen.
- **Sussy Notes:** A built-in note viewer with a sidebar featuring mysterious lore, developer messages, and project ideas.
- **Sussy Clicker:** An incremental clicker minigame with a crewmate counter, pop-up text animations, and local high score tracking.
- **Imposter Roulette:** A circular table survival game where clicking the wrong crewmate triggers a simulated windows blue screen.
